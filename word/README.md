# Microsoft 365 Word MCP Server

An MCP server for Microsoft Word integration, providing document management capabilities through Microsoft Graph API.

## Features

- List and search all Word documents across OneDrive
- Extract plain text content from Word documents (.doc and .docx formats)
- Create new Word documents with markdown content conversion
- Write and update document content with automatic markdown to DOCX conversion

## Usage

This MCP server is designed to run as part of [Obot](https://github.com/obot-platform/obot/). You can run Obot yourself or try it out on our free demo environment at [chat.obot.ai](https://chat.obot.ai).
